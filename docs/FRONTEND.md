# Current frontend documentation

The final frontend replaces the M3/M4 manual server-state fetching and hash listener with TanStack Query, session Context and React Router HashRouter. Original named component exports and behavioral tests are retained. Socket.IO adds authorized after-commit change hints and session-only notifications.

Read FRONTEND_ARCHITECTURE.md, COMPONENTS.md, REACT_HOOKS.md, TANSTACK_QUERY.md and REALTIME_ARCHITECTURE.md for the authoritative final design. API.md/WORKFLOW.md remain authoritative for backend permissions. ACCESSIBILITY.md/PERFORMANCE.md/VERIFICATION.md describe executed checks and their limits.
